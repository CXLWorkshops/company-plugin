# Frameworks

Reference playbooks the agents and skills in this plugin apply when relevant. These are read as background knowledge, not run as instructions on their own.

| File | Covers |
|---|---|
| `geo-optimization-best-practices.md` | Passage-level writing rules, query fan-out, comparison-page strategy, technical retrievability for LLM/answer-engine citation. Primary playbook for `aeo-geo-optimization`. |
| `seo-geo-revamp-frameworks.md` | Content audit and pruning (ROT / KICR), consolidation and cannibalization, GEO restructuring for a large content site. |
| `content-recycling-best-practices.md` | Extract-don't-syndicate repurposing, topic arcs, snippets-of-value selection. |
| `content-repurposing-frameworks.md` | Lightweight repurposing patterns across formats. |
| `b2b-content-funnels-with-ai-best-practices.md` | AI gap-analysis workflows, GEO recommendation strategy, bottom-of-funnel audits, content quality checklist, AI-phrasing blocklist. |

**Sourcing:** `geo-optimization-best-practices.md`, `content-recycling-best-practices.md`, and `b2b-content-funnels-with-ai-best-practices.md` are operational distillations of CXL Institute courses — see each file's frontmatter `source:` field for the specific course and instructor. They're shared here as reference material for teams using this plugin, not as a redistribution of the full course.
